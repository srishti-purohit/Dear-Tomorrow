# Dear Tomorrow

What if your perfect day could write back?

Dear Tomorrow is an interactive journaling experience where users write postcards from their future perfect days and turn them into small collections of memories and moments worth looking forward to.

The idea came from a simple question, that instead of making plans for the future, what if you could write from it? Dear Tomorrow invites users to imagine a future memory, describe it as a postcard, and build a recipe using carefully chosen ingredients that capture what made that day special.

## What it Does

- Write postcards from future memories
- Build a recipe using a curated set of ingredients
- Preview postcards as you write
- Save postcards locally in the browser
- Browse previously saved postcards in a gallery
- Explore the experience through a scrapbook-inspired interface

## How it Works

1. Imagine a future memory.
2. Write a postcard from that future day.
3. Build a recipe using the available ingredients.
4. Save your postcard.
5. View your saved postcards in the gallery.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Inspiration

A lot of productivity tools focus on goals, tasks, and outcomes. Dear Tomorrow focuses on memories instead.

The project encourages users to imagine their future through storytelling. By writing from a future moment rather than planning toward it, users are invited to reflect on what truly matters and what a fulfilling future might look like.

## Running Locally

```bash
npm install
npm run dev
```

Then open:

```txt
http://localhost:3000
```
